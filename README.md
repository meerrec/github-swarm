# GitHub Swarm

A responsive control center for coordinating AI engineering agents across repositories. This version uses realistic demo data and stores task changes in the current browser.

## Features

- Searchable and filterable task queue
- Agent fleet and live activity views
- Task creation, pause/resume, and completion
- Desktop and mobile layouts
- Installable PWA

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

## Stack

React, TypeScript, Vite, Tailwind CSS, Lucide icons.
